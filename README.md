# Amygdala

Amygdala синхронизирует общую папку Obsidian через Google Drive и Google Таблицы. Передаются заметки Markdown, Canvas, рисунки и вложения. Каждый участник входит в свой аккаунт Google и выбирает локальную общую папку. Папки у участников могут называться по-разному.

## Состояние выпуска

Эта ветка содержит кандидат выпуска, который ещё проходит проверку. Опубликованная версия в GitHub может отличаться от этой ветки. Проверка на Windows и Android должна быть подтверждена для конкретного номера релиза. iPhone не входит в текущий выпуск. `isDesktopOnly: false` само по себе не подтверждает такую проверку.

Старые командные проекты требуют отдельной [миграции с двумя этапами согласия](docs/MIGRATION.md). Подготовка резервной копии и проверка восстановления доступны без записи в Google. Новый механизм сначала закрывает старую публикацию в основной таблице, затем сохраняет и защищает сегменты. После новой полной резервной копии требуется отдельное разрешение для её точного снимка перед активацией. Перед активацией полный снимок проверяется повторно. Прерывания и поздние фрагменты проверяются локально; живая миграция и приёмка на реальных устройствах ещё не подтверждены. Не устанавливайте старую версию для отката проекта после смены схемы.

## Установка через BRAT

1. В Obsidian откройте **Настройки → Сторонние плагины → Обзор** и установите **BRAT**.
2. В настройках BRAT выберите **Add a beta plugin for testing** и добавьте `https://github.com/AdekWhat261/amygdala`.
3. Выберите опубликованную версию, указанную в инструкции к выпуску, и включите **Amygdala**.
4. Откройте **Настройки → Amygdala → Подключение** и войдите в свой Google.

На телефоне используется тот же путь через BRAT: вручную распаковывать файлы в скрытую папку не требуется. Минимальная заявленная версия Obsidian — 1.11.4. Если вместо BRAT используется ZIP, устанавливаются только `main.js`, `manifest.json` и `styles.css` в `.obsidian/plugins/amygdala-connection` выбранного хранилища.

## Подключение к команде

Владелец предоставляет участнику право редактировать существующую папку проекта в Google Drive. Это отдельный шаг от установки плагина: ссылка для просмотра не даёт права синхронизации. Для Team v4 в Google Picker выбираются Control и Data 1–8 одного проекта.

После подключения откройте **Настройки → Amygdala** и выберите **Папка проекта на этом устройстве → Выбрать папку**. Только содержимое выбранной папки участвует в командной синхронизации; заметки снаружи не переносятся по ссылкам. Подключение нового проекта оставляет автоматическую синхронизацию выключенной. Включение проверяет доступ и совместимость командного проекта. Для старой схемы сначала требуется согласованная миграция.

## Работа и восстановление

Создавайте заметки обычными средствами Obsidian, включая Ctrl+N. Amygdala не заменяет редактор. Для немедленного обмена используйте команду **Amygdala: Синхронизировать сейчас**. При независимых правках сохраняются конфликтные версии; открывайте их через **Показать конфликты Amygdala** и выбирайте итоговую версию.

Не включайте другой плагин синхронизации для той же общей папки. Настройки Obsidian и автоматически включённые плагины устройств не синхронизируются. Перед загрузкой обновления проверяйте номер версии и инструкцию восстановления для схемы проекта. Локальные заменённые файлы сохраняются в `.easy-sync/recovery`; это не заменяет полную резервную копию таблиц.

На Android обмен возобновляется при возвращении в приложение, если включена автосинхронизация. Постоянная работа в фоне не гарантируется. Если вход Google истёк или отозван, используйте **Переподключить** и повторно подтвердите выбранные таблицы. Пока OAuth-приложение находится в тестовом режиме, новые аккаунты могут требовать допуска владельцем сервиса, а повторный вход — чаще, чем в рабочем режиме.

## Приватность

Team v4 запрашивает `drive.file` для таблиц, выбранных пользователем. Данные общей папки хранятся в Google Таблицах и не имеют сквозного шифрования. При разрешённом публичном просмотре ссылку может читать любой её получатель. Личное подключение использует отдельное хранилище; перенос между личным и командным проектом автоматически не выполняется.

Файлы релиза не содержат настройки аккаунтов, `data.json`, токены, заметки или копии таблиц. Сервис входа: `https://easy-sync-login.igor-ryabkov.chatgpt.site`; он обслуживает вход и обновление доступа Google. Для диагностики сообщайте версию плагина, версию Obsidian, платформу и текст ошибки, исключая токены и содержимое личных заметок.

## Сборка

Исходники собираются на Node.js 24.19.0 без загрузки дополнительных зависимостей:

```text
node build.cjs
node run-tests.cjs
```

Сборка создаёт только необходимые файлы в `dist`. Автоматические тесты используют изолированные данные и не подтверждают установку либо обмен на реальных устройствах. Лицензия — MIT.
