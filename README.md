# Amygdala Connection 0.2.0 beta

Плагин Obsidian для синхронизации заметок через Google Drive. Версия 0.2 добавляет закрытый командный режим; личный режим 0.1 остаётся отдельным форматом.

Easy Sync 0.1 — прежнее название личного формата синхронизации. Практические инструкции находятся в [руководстве пользователя](USER_GUIDE.md).

## Режимы

- **Личное хранилище 0.1** — прежний формат в скрытом `appDataFolder` Google Drive. Старые локальные журналы и refresh token сохраняются. Автоматической миграции нет.
- **Командное хранилище 0.2** — обычная папка `Easy Sync — <название>` в Google Drive, манифест версии 2, история DAG и blobs только внутри выбранной папки. Для команды используются отдельные Google-вход, токен и локальный журнал.

Смешивать облачные форматы нельзя. Чтобы начать командную работу, создайте отдельную полную копию vault и загрузите её в новую командную папку. Личную облачную копию не удаляйте и не меняйте, пока новая копия не проверена.

## Подключение команды

1. Включите плагин на тестовой копии Obsidian и выберите «Командное хранилище 0.2».
2. Владелец входит в Google и создаёт командное хранилище. Плагин создаёт папку и манифест Amygdala Connection.
3. Владелец отправляет участникам ссылку Drive и подтверждает каждому запрос на редактирование средствами Google Drive.
4. Участник входит под своим Google-аккаунтом, вставляет ту же ссылку в Amygdala Connection и выбирает подключённую папку. Нужны права редактора.
5. Сначала подключайте устройства по одному и синхронизируйте полную копию. Нажмите «Проверить облачную копию» и убедитесь, что сверены все файлы. Переносите рабочий vault только после проверки и сделайте резервную копию.

Доступ проверяется перед каждым проходом: нужны права чтения содержимого и добавления файлов в выбранную папку. Отзыв прав останавливает проход до локальных замен и удалений. Плагин использует файловую область Drive для командной beta, потому что синхронизация должна перечислять дочерние файлы выбранной папки. Запросы Amygdala Connection содержат ID этой папки и проверяют её как родителя результатов; OAuth-согласие на широкий scope всё равно является требованием этой beta.

## OAuth beta

Bridge запрашивает узкий `drive.appdata openid email` для личного режима и `drive openid email` для командного. Google OAuth audience в testing mode ограничен добавленными тестовыми пользователями; согласие на доступ к Drive может потребовать повторного входа примерно раз в неделю. Добавляйте только участников закрытой beta. Не обещайте непрерывный фоновый вход.

Командные события содержат Google `permissionId`, отображаемое имя, ID устройства и дату; адрес электронной почты нужен локально для идентификации аккаунта и не пишется в историю событий. Доступ к файлам обеспечивает Google Drive. Сквозного шифрования нет. Не помещайте в beta-хранилище секреты и данные, которые команда не готова хранить в Drive.

## Конфликты и восстановление

- Одновременные правки остаются отдельными вершинами DAG. Варианты лежат в `.easy-sync/conflicts` и исключены из повторной загрузки как обычные заметки.
- Команда «Показать конфликты Amygdala Connection» показывает авторов, устройства, дату и построчное сравнение Markdown. Можно открыть оба варианта, выбрать один или вручную объединить текст.
- Решение записывает новую ревизию с обеими конфликтующими вершинами в `parents`, поэтому конфликт закрывается на всех устройствах после синхронизации.
- Конфликт удаления показывается отдельным вариантом. Перед любой заменой и удалением локальная копия попадает в `.easy-sync/recovery`.
- Бинарные файлы сравниваются по контрольным суммам; выберите копию в окне конфликтов и сохраните её как новую ревизию.

## Что синхронизируется

Заметки, теги, свойства, ссылки, рисунки Excalidraw и вложения передаются без конвертации. SHA-256 проверяется до загрузки и после скачивания. Внутренние папки `.easy-sync`, `.obsidian`, `.trash` и `.git` исключены. Настройки и включённые плагины устройств не синхронизируются. В командном хранилище можно отдельно опубликовать список предложенных плагинов; участники сами принимают или отклоняют каждое предложение, а скачанный плагин не включается автоматически. Один файл может занимать не более 100 МиБ. Синхронизация работает, пока Obsidian открыт; работа приложения в фоне на телефоне не гарантируется. Не запускайте для одного vault два механизма синхронизации.

## Разработка и установка

Нужен Node.js 22 или новее.

```text
node --test test/*.test.cjs test/*.test.mjs
node build.cjs
```

Для ручной установки скопируйте `dist/main.js`, `dist/manifest.json`, `dist/styles.css` в `.obsidian/plugins/amygdala-connection` тестовой копии vault. Публикация для BRAT выполняется из Git-репозитория с настроенным GitHub remote; ZIP — резервный способ установки. Локальная сборка или коммит сами по себе не означают опубликованный релиз.

## OAuth bridge

Инструкции по конфигурации Google OAuth и развертыванию bridge см. в [bridge/README.md](bridge/README.md). Bridge не получает содержимое файлов и не сохраняет токены в базе. До отдельного развёртывания обновлённого bridge командный вход не заработает на удалённом сервисе.
