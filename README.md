# Amygdala 0.3.0 beta

Плагин Obsidian для синхронизации заметок через Google Drive. Командный формат 0.3 хранит журнал и вложения в одной служебной Google Таблице внутри общей папки; личный режим 0.1 остаётся отдельным форматом.

Easy Sync 0.1 — прежнее название личного формата синхронизации. Инструкции для пользователей находятся в [руководстве](USER_GUIDE.md).

## Режимы

- **Личное хранилище 0.1** — прежний формат в скрытом `appDataFolder`. Старые локальные журналы и refresh token сохраняются; автоматической миграции нет.
- **Командное хранилище 0.3** — обычная папка `Amygdala — <название>` с одной служебной таблицей формата 3. В ней хранятся события DAG, индекс и части файлов. Каждый участник выбирает именно таблицу в Google Picker, выдавая Amygdala доступ `drive.file` к этому файлу. Для команды используются отдельные Google-вход, токен и локальный журнал.
- **Старое командное хранилище 0.2** продолжает работать в отдельном режиме для уже существующих папок. Оно по-прежнему использует широкий scope `drive`; подключайте его только ради старого vault. Новую команду начинайте с формата 0.3.

Форматы не смешиваются. Для перехода создайте отдельную полную копию vault и загрузите её в новое командное хранилище. Личную облачную копию не переносите и не изменяйте.

## Подключение команды

1. Установите beta на копию Obsidian и выберите «Командное хранилище 0.3».
2. Владелец входит в Google и создаёт командное хранилище. Amygdala создаёт папку и служебную таблицу.
3. Владелец отправляет участникам ссылку на папку Drive и подтверждает каждому запрос редактора средствами Google.
4. Участник указывает свой Google-аккаунт, запускает подключение и выбирает служебную таблицу Amygdala в Picker. Нужны права редактора на общую папку и таблицу.
5. Подключайте устройства по одному, синхронизируйте полную копию и проверьте её перед переносом рабочего vault.

Перед каждым проходом проверяются манифест, расположение таблицы и `capabilities.canEdit`. При отзыве прав синхронизация останавливается до локальных замен и удалений. Командный OAuth 0.3 запрашивает `drive.file`; личный режим использует отдельный `drive.appdata` вход. Старый team 0.2 сохраняет широкий scope `drive` и остаётся отдельным; ничего не переносится автоматически.

В тестовом режиме Google может потребовать повторный вход примерно через неделю. Владелец OAuth-приложения должен добавить аккаунты участников в список тестировщиков. Bridge не получает содержимое заметок и не сохраняет токены в базе.

## История, конфликты и восстановление

- События содержат Google `permissionId`, отображаемое имя, ID устройства и дату. Email используется локально для проверки участника, но не добавляется в журнал.
- Одновременные правки остаются отдельными вершинами DAG; варианты лежат в `.easy-sync/conflicts` и не загружаются как заметки.
- Amygdala показывает автора, устройство, дату и построчное сравнение Markdown. Можно открыть обе версии, выбрать одну или сохранить ручное объединение.
- Разрешение создаёт ревизию с обеими вершинами в `parents`, закрывая конфликт для команды после синхронизации.
- Перед любой заменой или удалением локальная копия сохраняется в `.easy-sync/recovery`.
- Blobs разбиваются на индексированные Base64-фрагменты в таблице и проверяются по SHA-256 до загрузки и после чтения.

Настройки и включённые плагины устройств не копируются. Amygdala позволяет отдельно публиковать список предложенных командных плагинов; участники сами принимают или отклоняют каждое предложение. Синхронизация работает, пока Obsidian открыт; работа приложения в фоне телефона не гарантируется. Не запускайте два механизма синхронизации для одного vault.

## Проверка и выпуск

Нужен Node.js 22 или новее.

```text
node --test test/*.test.cjs test/*.test.mjs
node build.cjs
```

Тесты проверяют DAG, обратную совместимость личного режима, bridge, таблицу, журнал и блобы. До выпуска остаются реальные проверки Picker и доступа двумя Google-аккаунтами на Windows и телефоне. Не считайте зелёные unit-тесты подтверждением работы Google OAuth.

После проверки выпускаются GitHub Release файлы `main.js`, `manifest.json`, `styles.css`; репозиторий можно установить через BRAT. Подробности входа и развертывания см. в [`bridge/README.md`](bridge/README.md).

### Установка beta через BRAT

1. На компьютере установите **BRAT** из каталога сторонних плагинов Obsidian.
2. Откройте палитру команд и выполните **BRAT: Add a beta plugin for testing**, затем введите `AdekWhat261/amygdala`.
3. Выберите последнюю версию Amygdala, затем включите её в **Настройки → Сторонние плагины**.

На телефоне шаги те же: BRAT загружает файлы релиза напрямую в vault; вручную распаковывать архив и работать с файловым менеджером не нужно. Для первой проверки используйте копию vault.
